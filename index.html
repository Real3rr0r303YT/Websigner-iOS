Sign any IPA and install it from Safari

Drop in an IPA, your .p12 certificate and provisioning profile. Everything is checked in your browser, then signed with zsign in GitHub Actions on your own repository, and you get an install button.

          2. Sign & install

          Signing runs in GitHub Actions on your repository (a fork of this one).

          Which token do I need?

          Create a fine-grained token for your repository only, with these repository permissions:

          • Contents: Read and write
          • Actions: Read and write
          • Secrets: Read and write
          • Pages: Read and write (optional, used to speed up publishing)

          The token is only sent to api.github.com. Unless you tick “Remember”, it's forgotten when you close the tab.

            What happens to my files?
            • The IPA, certificate and profile are checked locally. Nothing is uploaded until you press the button.
            • Your .p12, its password and the profile are encrypted in your browser with your repository's public key and stored as GitHub Actions secrets.
            • The IPA is encrypted with a one-time AES key and uploaded to a temporary branch.
            • After signing, the secrets and the temporary branch are deleted.
            • The signed IPA is published in the websigner release so iOS can download it. Anyone with the link can download it.
            • Whether Apple has revoked your certificate can't be checked from the browser.

            DNS / Anti-Revoke Guide

            Keep your apps from being revoked

            iOS checks with Apple whether a signing certificate is still valid. If Apple revokes it, your apps stop opening. Blocking those checks with NextDNS helps keep installed apps working.

            Create a free NextDNS account

            Go to my.nextdns.io and sign up. A new configuration is created for you, with an ID like abc123.

            Block Apple's revocation servers

            Open the Denylist tab and add the following domain:

            ppq.apple.com

            ppq.apple.com is the server iOS asks to check whether an app's certificate is still valid. Blocking it is enough for most users.

            Optional, for stronger protection (may affect some Apple services):

            ocsp.apple.com ocsp2.apple.com crl.apple.com valid.apple.com

            Install the NextDNS profile on your device

            On your iPhone or iPad, in Safari:

            • In NextDNS, open the Setup tab and choose Apple, or go straight to apple.nextdns.io.
            • Enter your configuration ID and tap Download.
            • Go to Settings → General → VPN & Device Management, tap the downloaded profile and choose Install.

            Verify DNS is active

            Visit test.nextdns.io. It should show "status": "ok" along with your configuration ID.

            Install and trust the app

            With DNS active, tap Install App above. When it finishes:

            • Go to Settings → General → VPN & Device Management, select the developer certificate and tap Trust.
            • If iOS asks you to, turn on Developer Mode under Settings → Privacy & Security.
            Heads up: Keep the NextDNS profile enabled at all times, including on cellular. If it is off even briefly while your device reaches Apple, a revoked certificate can take effect. DNS blocking lowers the risk of revocation but cannot guarantee it won't happen, and Apple may change its servers at any time.
